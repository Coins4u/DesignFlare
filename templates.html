Common Questions

What tech stack do I need?

Low tiers use plain HTML/CSS — any editor works. Mid tiers require Node.js for Next.js 14. High tiers use React 18 + Tailwind CSS. All include README setup guides.

How many files are in each pack?

Essential Pack: 45+ · Starter: 65+ · Creative Kit: 75+ · Growth Pro: 95+ · Professional Suite: 110+ · Business Elite: 140+ · Complete Marketing: 160+ · Ultimate Collection: 200+.

Can I use these for client projects?

Yes. All tiers include commercial use. Complete Marketing and Ultimate Collection include white-label rights for agency client delivery.

Do I need design skills?

Basic HTML/CSS knowledge helps for low tiers. Developer kits assume familiarity with React. Each file is documented and structured for easy customization.
